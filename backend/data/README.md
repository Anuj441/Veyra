# IBM Telco Customer Churn dataset

`WA_Fn-UseC_-Telco-Customer-Churn.csv` is the public IBM Telco Customer Churn sample dataset. It is sourced from IBM's public repository:

<https://github.com/IBM/telco-customer-churn-on-icp4d/tree/master/data>

The CSV is intentionally ignored by Git so raw customer records are not committed. Download the upstream `Telco-Customer-Churn.csv` and save it using the expected filename above. The downloaded file contains 7,043 records and is used directly by the training and analytics code; no generated customer data is substituted.
